# 💰 Nyukzin Wallet Backend

Nyukzin Wallet Backend is a secure and scalable REST API built to power the Nyukzin Wallet platform. It provides authentication, wallet management, transaction processing, user management, and financial services through a robust Java-based architecture.

## Features

- User Registration and Authentication
- JWT-Based Security
- Wallet Creation and Management
- Deposit and Withdrawal Processing
- Fund Transfers
- Transaction History
- Role-Based Access Control
- Account Verification
- RESTful API Architecture
- Secure Financial Operations
- Audit Logging

## Architecture

The backend follows a layered architecture:

- Controllers (API Endpoints)
- Services (Business Logic)
- Repositories (Data Access Layer)
- Models/Entities
- Security Layer
- Database Layer
